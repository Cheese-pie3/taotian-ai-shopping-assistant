# 帮我凑对 V10｜淘天产品经理面试展示版

这是一个基于 Streamlit 的购物车 AI 下单陪跑助手 Demo。它不是可直接上线的工程系统，而是用于产品经理面试展示的交互原型：验证大促场景下“先算钱、再解释、再给下一步”的 AI 陪跑链路。

## 一句话定位

618 大促场景下，用户购物车已有商品但看不懂复杂优惠。本 Demo 演示 AI 如何帮助用户判断：直接买、凑单买，还是再等等。

## 运行方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 面试展示重点

1. 首屏说明用户痛点、原型目标和 Demo 边界。
2. 支持搜索模拟凑单品并加入购物车，实时重算商品总额、实付金额和优惠状态。
3. AI 面板用“结论 / 关键证据 / 风险提醒 / 下一步”统一表达。
4. 用户意图会影响凑单候选排序：最省钱、不乱买、最省心、最快到、等低价。
5. 凑单卡片展示完整计算证据：成本、直接买、加入后实付、差额、门槛、结论和风险。
6. 底部补充产品判断、真实落地依赖和核心指标，便于面试讲解。

## Demo 边界

当前为作品集 Demo，使用模拟购物车和模拟优惠规则。不接入真实淘宝/京东 API。不声称识别所有隐藏优惠、直播券或真实历史价格。真实平台落地需要接入购物车、营销、用户权益、价保、直播和价格历史 API。

## 面试讲解建议

可以这样开场：

> 我没有把它包装成一个真实可上线系统，因为真实落地必须依赖平台内部购物车、营销、权益、价格历史和价保 API。这个 Demo 的价值在于，我把复杂大促决策拆成了可解释的产品流程：先算清楚，再判断是否值得凑单，最后用用户能理解的话给出买/等建议。
