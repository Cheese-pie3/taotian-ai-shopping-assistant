# 帮我凑对｜大促购物车 AI 下单陪跑助手

一句话介绍：
一个基于模拟数据的 AI 产品原型，用于探索大促复杂优惠场景下，平台如何帮助用户理解优惠、判断凑单、做出更安心的下单决策。

## 项目背景
大促期间，用户面对满减、店铺券、会员券、直播券、国补等多种优惠，经常难以判断是否真的省钱。现有博主攻略更适合有时间研究规则的用户，无法覆盖更广泛的普通消费者。

## 核心问题
- 用户不知道哪些优惠已生效
- 用户不知道凑单后是否真的更便宜
- 用户不知道是否存在隐藏优惠
- 用户担心商家先涨价再降价
- 用户缺少下单前的解释型助手

## 产品方案
本原型设计了一个购物车 AI 下单陪跑助手，围绕五个步骤展开：
1. 诊断购物车
2. 检查优惠
3. 判断凑单
4. 买/等决策
5. 价保提醒

## Demo 能力
- 模拟多商品购物车
- 支持用户勾选本次结算商品
- 支持搜索并添加模拟凑单品
- 支持手动勾选优惠券
- 默认推荐可叠加、高优先级优惠
- 根据规则引擎计算实付金额
- 用 AI 面板解释结论、证据、风险和下一步

## 技术与实现说明
当前 Demo 使用：
- Streamlit 构建交互界面
- CSV 模拟购物车、优惠券、凑单品和价格历史
- 规则引擎计算优惠是否生效和凑单结果
- 模板化回复模拟 AI 解释层

## 项目边界
当前版本不接入真实淘宝 / 京东 / 淘天 API，不读取真实购物车数据，不识别真实隐藏优惠或价格历史。  
该项目重点在于验证产品流程、交互方式和 AI 解释链路。

## 真实落地依赖
若在真实平台落地，需要接入：
- 购物车数据
- 用户已领券数据
- 营销活动数据
- 直播间券 / 会场券 / 国补资格
- 价格历史
- 订单与价保 API

## 指标设计
可以关注：
- 优惠使用率
- 凑单建议采纳率
- 下单转化率
- 用户决策时长
- 价保提醒开启率
- AI 解释满意度
- 不必要凑单减少率
