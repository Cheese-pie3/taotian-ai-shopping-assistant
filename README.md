# 帮我凑对｜大促购物车 AI 下单陪跑助手

一个面向大促购物车场景的 AI 产品原型：当用户看不懂复杂优惠、不确定是否值得凑单、担心先涨后降时，AI 帮用户先算清楚，再解释原因，最后给出下一步建议。

> This is an AI product prototype for festival shopping-cart decision support. It focuses on explainable promotion calculation, add-on recommendation, and buy-or-wait guidance.

## 在线 Demo

https://taotian-ai-shopping-assistant-gdweu8nb7xvx9uxetyiern.streamlit.app/

## 项目定位

这不是一个声称可直接上线的工程系统，而是一个用于验证大促购物决策体验的 AI 产品原型。它重点展示：

- 如何从真实电商场景中拆解用户痛点；
- 如何把复杂优惠规则转化为可解释的 AI 产品流程；
- 如何用交互原型验证产品路径；
- 如何定义真实平台落地所需的数据、接口、风控和指标。

## 用户痛点

大促期间，用户常常面对满减、店铺券、会员券、直播间券、国补、红包、价保等多种规则：

1. 不知道哪些优惠已经生效，哪些还差门槛；
2. 不知道凑单后是否真的更便宜；
3. 担心商品存在先涨价再降价；
4. 不想花时间研究攻略，但又怕买贵；
5. 希望平台在结算前给出清楚、可信、可行动的建议。

## 产品方案

本 Demo 将大促购物决策拆成 5 个环节：

1. **购物车诊断**：识别当前勾选商品、总额、优惠状态和未生效规则。
2. **优惠解释**：说明每张券为什么生效或未生效。
3. **凑单判断**：计算加入候选凑单品后，是否真的少付。
4. **买 / 等建议**：结合大促阶段、价格诚意和用户意图给出建议。
5. **价保提醒**：降低用户对后续降价的焦虑。

AI 面板统一采用：

```text
结论
关键证据
风险提醒
下一步
```

这样可以避免 AI 只“聊天”，而是输出可验证、可执行的交易决策辅助。

## Demo 功能

- 模拟购物车商品勾选；
- 模拟优惠券勾选与生效状态计算；
- 搜索并加入凑单候选品；
- 根据购物车变化实时重算实付金额；
- 按用户意图调整推荐策略：最省钱、不乱买、最省心、最快到、等低价；
- 展示凑单前后实付差异、门槛、成本和风险；
- AI 解释面板输出结构化建议；
- 底部补充产品价值、真实落地依赖和验证指标。

## 项目边界

当前 Demo 使用模拟数据，不接入真实淘宝、天猫、京东或其他电商平台 API。

它不读取真实购物车，不识别真实用户权益，不承诺最低价，也不声称能发现所有隐藏优惠。

如果真实落地，需要平台内部支持：

- 购物车数据；
- 营销权益与优惠券数据；
- 直播间券、国补、会场券等权益数据；
- 商品价格历史；
- 价保规则；
- 用户分层与风控策略；
- 实际结算金额校验能力。

## 指标与实验思路

如果上线验证，不应只看 GMV，也要看用户是否真正理解优惠、是否减少无意义凑单、是否提升对平台大促透明度的信任。

建议关注：

- 优惠理解率；
- 未生效优惠原因查看率；
- 凑单建议点击率与采纳率；
- 凑单后实付降低比例；
- 用户决策时长；
- 购物车结算转化率；
- 推荐后退款率 / 取消订单率；
- “被误导凑单”反馈率；
- AI 建议与实际结算金额不一致率。

## 技术实现

- 前端与交互：Streamlit
- 数据：CSV 模拟购物车、优惠规则、价格历史、凑单品、促销日历
- 规则计算：Python 规则引擎
- AI 解释：模板化解释链路，模拟大模型输出结构
- 推荐逻辑：结合优惠门槛、实付差额、用户意图和风险提示排序

## 项目结构

```text
app.py                         # Streamlit 主应用
modules/
  rule_engine.py               # 优惠规则计算
  decision_engine.py           # 买/等/凑单决策
  addon_recommender.py         # 凑单品推荐
  price_sincerity.py           # 价格诚意判断
  llm_explainer.py             # AI 解释文案生成
data/
  cart.csv                     # 模拟购物车
  coupon_rules.csv             # 模拟优惠规则
  add_on_products.csv          # 模拟凑单品
  price_history.csv            # 模拟价格历史
  promotion_calendar.csv       # 大促阶段
docs/
  prd_v9.md                    # PRD 与交互说明
  demo_walkthrough.md          # Demo 演示流程
api_mock/
  next_action_request.json
  next_action_response.json
```

## Demo 演示流程

建议按以下顺序体验：

1. 查看购物车中已勾选商品和当前优惠状态；
2. 勾选或取消优惠券，观察实付金额变化；
3. 搜索并加入凑单候选品；
4. 对比凑单前后的实付金额、门槛和风险；
5. 阅读 AI 面板给出的结论、证据、风险提醒和下一步；
6. 查看底部的真实落地依赖和指标验证思路。
